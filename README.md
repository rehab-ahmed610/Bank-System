# Bank Management System (C++)

A console-based Bank Management System developed in C++ applying structured programming, file handling and data structures (`struct`, `vector`).

## 🎥 Live Demo Video
👉 [Click here to watch the project demo video on Google Drive](https://drive.google.com/file/d/1gAalopCV3qaJBm4AGyZRIuoYASnkEuzF/view?usp=drivesdk)

## ✨ Key Features
* **Client Management:** Add, update, delete, find, and list all bank clients persisted in a text file (`clientsfile.txt`).
* **Transactions Module:** Deposit, withdraw, and view total balances across all accounts.
